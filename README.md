# quasimod_p
Quasimod (Mod for Quasimorph)

Mod Content:

=========== Gameplay:
- Missions:
					- Faction takeover mission is generated always at max difficulty
					- Additional floor difficulty preset:
												- max value raised to 8
												- act as MAX additional floors (missions additional floors are now randomized)
					- Mission Control HUD icon would flash when you finished your current floor objectives

- Magnum:			- added extra Cargo Holds (optional up to 3, new game required)
					- newly generated Magnum Cargo are expanded to 36 rows (configurable)

- Magnum Upgrades:			
					- Deparments are decoupled. You don't need to upgrade half of the perk tree to unlock them
					- Deparements upgrades cost additional resources to account for early accessibility.
					- addeded "Magnum Upgrades cost double" toggleable setting
					- Scavengers Department:
												- finding extra items after completed mission is not guaranteed, it has ~ 1/3 chance to do so (every item is rolled separetely)
 
- Magnum Projects: 
					- Genome Project:
												- some parameters are capped, steps slightly adjusted

- Mercenaries:		- Starvation from running slightly reduces

- Mercenary Perks:
					- Bodybuilding:  was nerfed 10/20/40/60
					- Ranks: all ranks were slightly buffed and rebalanced: early utility and later combat power

- Mercenary Classes:
					- all classes have now free perk slot you could use in Mercenary Class Project

- Enemies:
					- Loot drops were rebalanced: 
												- valuable items are more rare (such as barter items and data items)
												- food is more common
												- quest enemies are not affected
					- Eccolapsing enemies:
												- invulnerability was removed; incoming attacks has 50% chance to miss and would deal reduced damage.
													
- Items:			
					- Items like food box, weapon box, drug cargo, etc.:
												- disassemble drop is guaranteed, but in lesser quantities and sometimes the luck may intervene. (this also true when disassembling at recycler)
					- weapon box :
												- disassembling yields only weapons, drop table was expanded

					- Duffel Bag : buffed durability to 30 (less more annoying jungling bags around)

- Difficulty:		- Added new difficulty balanced around the mod


=========== QOL:
- Prepare for Mission Screen:
					- added mission tooltip when hovering on the mission type/name
- Mission tooltip:
					- removed useless rooms info
					- mission difficulty set to "5 skull mode" (toggleable)
- Keybindings:
					- added keybinds for switching to Stealth/Walk/Run mode directly
					- added keybind for toggling camera mode: Locked on Player/Free

- Mercenaries Screen:
					- added buttons to sort mercenaries.
