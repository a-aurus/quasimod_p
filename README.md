## Quasimod (Mod for Quasimorph)

------------------------------
## 🎮 Gameplay

* **Expanded Noise Mechanics:**
    * Running or walking now generates sound that could alert nearby enemies:
        * Running next to a wall can alert enemies standing close in the adjacent room.
        * Walking is generally unnoticeable and will not feel drastically different in most situations.
    * Projectiles hitting a wall will now also alert nearby enemies.

* **Rebalanced Enemies:**
    * **AI Tweaks:** 
        * Implemented experimental logic to prevent the AI from getting trapped or stuck in large groups when investigating.
        * Enemies will now react if they see the player, even during the player's turn (no more "peekaboo" peeking).
    * **Eclypse:**
        * Invulnerability was removed; incoming attacks now have a 50% chance to miss and will deal reduced damage.
    * **Quasimorphosis:**
        * Added a setting to change how much quasimorphosis is generated upon a quasimorph's death (default 50%).
        * It supports negative values for those who want to "expel them back" (-0.25 generally removes half of the quasimorphosis generated by killing a human).
    * **Stat Adjustments:**
        * Human enemies, as well as some other units, have been slightly rebalanced.

* **Missions:**
    * **Mission Floor Scaling:**
        * The maximum value for the "Additional floor" difficulty preset has been raised to 8.
        * Rather than applying as a flat increase, this value now represents the cap for a randomized number of additional floors generated for each mission.
        * The Mission Control HUD icon now flashes when you finish your current floor objectives.

* **Magnum:**
    * **Expanded Cargo:**
        * Added extra Cargo Holds (optional up to 3, new game required).
        * Newly generated Magnum Cargo space is expanded up to 36 rows (also configurable).
    * **Department Upgrades:**
        * Departments are now decoupled. You do not need to upgrade half of the perk tree to unlock them.
        * Department upgrades cost additional resources to account for early accessibility.
        * Added a setting to double all Magnum upgrade costs.
    * **Scavengers Department:** 
        * Finding extra items after a completed mission is not guaranteed (a ~1/3 chance is rolled separately for every item).
    * **Genome Project:** 
        * Some parameters were slightly rebalanced.
   
* **Mercenaries:**
    * **Mercenary Classes:**
        * All classes now have a free, unassigned perk slot you can utilize in the Mercenary Class Project.
    * **Perks:**
        * Ranks were rebalanced to give utility in the early game and combat power at higher ranks.
        * A few class perks were also rebalanced.
    * **General:**
        * Starvation accumulated from running has been slightly reduced.

* **Items:**
    * **New Container Drop Mechanics:**
        * Disassembling items like food boxes, weapon boxes, etc., yields a guaranteed drop, but in lesser quantities. Luck may occasionally intervene.
        * This logic also applies when disassembling items at the recycler.
        * Weapon boxes now feature a wider variety of weapons but will no longer drop ammo.
    * **Safer Drugs:**
        * Reduced alcohol, cigarette, and morphine addiction chances, as previous rates were too punishing to make using them worthwhile.
        * Decreased the quasimorphosis reduction of morphine to -120, as it was primarily being exploited to lower quasimorphosis instead of being used as an actual medical item.     
    * **General Stat Tweaks:**
        * Adjusted values for several core item attributes, including durability and stack sizes.

* **Difficulty:**
    * **Fair+:** A brand new difficulty mode specifically balanced around the mod's features.

------------------------------
## ⚙️ QOL

## 🖥️ UI
* Mission tooltips will now display when hovering over the mission type or name. The displayed mission difficulty has two modes: "vanilla" and "5-skull mode" (toggled in settings).
* Added a new button to pause time on the Space Screen.
* Added the ability to sort your mercenary clones.

## ⌨️ Controls
* **New Keybindings:** 
    * Keybinds to switch directly to Stealth, Walk, or Run mode.
    * Keybind to toggle the camera between Locked on Player and Free camera modes.

------------------------------
## 🛠️ Configuration & Settings
* Settings are stored in the configuration file located at: `%AppData%\LocalLow\Magnum Scriptum LTD\Quasimorph`
* Includes an option to completely disable experimental features in case they cause stability issues.
* An in-game settings menu will be added in a future update.
