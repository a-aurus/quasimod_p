# Quasimod (Mod for Quasimorph)

Mod Content:

## 🎮 Gameplay
* **Missions:**
    * Faction takeover mission is generated always at max difficulty
    * Additional floor difficulty preset:
        * Max value raised to 8
        * Act as MAX additional floors (missions additional floors are now randomized)
    * Mission Control HUD icon would flash when you finished your current floor objectives
* **Magnum:**
    * Added extra Cargo Holds (optional up to 3, new game required)
    * Newly generated Magnum Cargo are expanded to 36 rows (configurable)
* **Magnum Upgrades:**
    * Departments are decoupled. You don't need to upgrade half of the perk tree to unlock them
    * Departments upgrades cost additional resources to account for early accessibility.
    * Added "Magnum Upgrades cost double" toggleable setting
    * **Scavengers Department:** Finding extra items after completed mission is not guaranteed, it has ~ 1/3 chance to do so (every item is rolled separately)
* **Magnum Projects:**
    * **Genome Project:** Some parameters are capped, steps slightly adjusted
* **Mercenaries:**
    * Starvation from running slightly reduces
* **Mercenary Perks:**
    * **Bodybuilding:** Was nerfed 10/20/40/60
    * **Ranks:** All ranks were slightly buffed and rebalanced: early utility and later combat power
* **Mercenary Classes:**
    * All classes have now free perk slot you could use in Mercenary Class Project
* **Enemies:**
    * **Loot drops were rebalanced:**
        * Valuable items are more rare (such as barter items and data items)
        * Food is more common
        * Quest enemies are not affected
    * **Eccolapsing enemies:** Invulnerability was removed; incoming attacks has 50% chance to miss and would deal reduced damage.
* **Items:**
    * **Items like food box, weapon box, drug cargo, etc.:** Disassemble drop is guaranteed, but in lesser quantities and sometimes the luck may intervene. (This also true when disassembling at recycler)
    * **Weapon box:** Disassembling yields only weapons, drop table was expanded
    * **Duffel Bag:** Buffed durability to 30 (less more annoying juggling bags around)
* **Difficulty:**
    * Added new difficulty balanced around the mod

## ⚙️ QOL (Quality of Life)
* **Prepare for Mission Screen:**
    * Added mission tooltip when hovering on the mission type/name
* **Mission tooltip:**
    * Removed useless rooms info
    * Mission difficulty set to "5 skull mode" (toggleable)
* **Keybindings:**
    * Added keybinds for switching to Stealth/Walk/Run mode directly
    * Added keybind for toggling camera mode: Locked on Player/Free
* **Mercenaries Screen:**
    * Added buttons to sort mercenaries.
